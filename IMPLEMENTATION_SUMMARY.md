## 🚀 Quick Start Guide

### Step 1: Verify Build Success
```bash
cd /Users/admin/Documents/GitHub/MobileWebAutomationFramework_Java
mvn clean install
# Should see: BUILD SUCCESS
```

### Step 2: Configure for Your Application

**For Web Testing (Chrome):**
```bash
# Edit src/main/resources/config.properties
APP_TYPE=web
BROWSER=chrome
URL=https://your-app.com
IMPLICIT_WAIT=10
```

**For Android Native Testing:**
```bash
# Edit src/main/resources/config.properties
APP_TYPE=mobile
MOBILE_OS=android
APP_MOBILE_TYPE=native
APPIUM_SERVER_URL=http://127.0.0.1:4723
ANDROID_DEVICE_NAME=your-device-name
ANDROID_PLATFORM_VERSION=13
ANDROID_APP_PATH=/path/to/your/app.apk
```

**For iOS Web Testing:**
```bash
# Edit src/main/resources/config.properties
APP_TYPE=mobile
MOBILE_OS=ios
APP_MOBILE_TYPE=web
APPIUM_SERVER_URL=http://127.0.0.1:4723
IOS_DEVICE_NAME=iPhone 15
IOS_PLATFORM_VERSION=17.0
```

### Step 3: Create Your Test Class
```java
package org.example.tests;

import org.example.base.BaseTest;
import org.testng.Assert;
import org.testng.annotations.Test;

public class MyAppTest extends BaseTest {

    @Test(description = "My first test")
    public void testMyApp() {
        // For web tests, use webDriver
        String title = webDriver.getTitle();
        Assert.assertNotNull(title);

        // For mobile tests, use mobileDriver
        // Assert.assertNotNull(mobileDriver);
    }
}
```

### Step 4: Run Your Tests
```bash
mvn test
# OR for specific test:
mvn test -Dtest=MyAppTest
```

## 🔧 Key Features

### 1. **Property-Based Configuration**
- Externalize all configuration to `config.properties`
- Support for string, integer, and boolean properties
- Easy switching between web and mobile testing
- Supports multiple browsers and mobile devices

### 2. **Automatic Driver Management**
- Drivers are automatically created in `@BeforeMethod`
- Drivers are automatically closed in `@AfterMethod`
- No manual driver management needed in test code

### 3. **Flexible Capability Management**
- Support for Chrome, Firefox, and IE options
- Support for Android native and web apps
- Support for iOS native and web apps
- Capabilities loaded from configuration file

### 4. **Comprehensive Logging**
- Log4j integration for detailed logging
- All logs written to `logs/automation.log`
- Configurable log levels (INFO, DEBUG, ERROR)

### 5. **TestNG Integration**
- Full TestNG support with annotations
- Test grouping and parallel execution support
- TestNG XML configuration for test suites

### 6. **WebDriverManager Integration**
- Automatic driver binary management
- No need to manually download drivers
- Works with Chrome, Firefox, and IE

## 🔍 File Descriptions

### DriverFactory.java
**Purpose:** Creates and manages WebDriver and AppiumDriver instances

**Key Methods:**
- `getWebDriver()` - Returns WebDriver for web testing
- `getMobileDriver()` - Returns AppiumDriver for mobile testing
- `getDriver()` - Returns driver based on APP_TYPE configuration
- `closeDriver(WebDriver)` - Closes WebDriver instance
- `closeMobileDriver(AppiumDriver)` - Closes AppiumDriver instance

### CapabilityFactory.java
**Purpose:** Creates browser options and Appium capabilities

**Key Methods:**
- `getChromeCapabilities()` - Chrome options
- `getFirefoxCapabilities()` - Firefox options
- `getInternetExplorerCapabilities()` - IE options
- `getAndroidNativeCapabilities()` - Android native capabilities
- `getAndroidWebCapabilities()` - Android web capabilities
- `getIOSNativeCapabilities()` - iOS native capabilities
- `getIOSWebCapabilities()` - iOS web capabilities

### ConfigurationManager.java
**Purpose:** Loads and manages properties from config.properties

**Key Methods:**
- `getProperty(String key)` - Get string property
- `getProperty(String key, String defaultValue)` - Get with default
- `getPropertyAsInt(String key)` - Get integer property
- `getPropertyAsBoolean(String key)` - Get boolean property

### BaseTest.java
**Purpose:** Abstract base class for all test classes

**Features:**
- `@BeforeMethod` - Initializes driver before each test
- `@AfterMethod` - Closes driver after each test
- Supports both webDriver and mobileDriver
- Automatic driver selection based on configuration
